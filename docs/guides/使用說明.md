## 1. 環境準備（只做一次）

> 換新電腦的完整步驟另見 [`SETUP.md`](setup.md)。以下假設已裝好 Python 3.13、Node.js v24、Git。

```powershell
cd C:\Users\User\OneDrive\Desktop\Albee_Stock

# 後端：建虛擬環境 + 裝依賴 + 建資料庫（Alembic 遷移）
setup.bat

# 前端：裝依賴
cd frontend
npm install
cd ..
```

### 設定金鑰（`.env`）

根目錄要有 `.env`（含 Alpaca 金鑰，**不進 git**）。沒有就從範本複製：

```powershell
copy .env.example .env
```

打開 `.env` 確認這幾行（預設就是安全的模擬模式）：

```
ALPACA_API_KEY=你的_PK開頭金鑰
ALPACA_SECRET_KEY=你的_Secret金鑰
ALPACA_BASE_URL=https://paper-api.alpaca.markets   # Paper（模擬，安全）
ALLOW_LIVE_TRADING=false                           # 真錢防線，先別動
```

### （選用）AI 思考助手 / AI 探勘情緒打分

要用本機 LLM（完全免費、資料不外洩）：

```powershell
# 1. 安裝 Ollama：https://ollama.com
ollama pull llama3.1   # 下載模型
ollama serve           # 啟動本機 LLM 服務
```

沒裝也能跑——AI 助手會回優雅的 400 提示，其餘功能照常。

## 2. 每次啟動（開兩個終端機）

直接雙擊根目錄的 `.bat`，或手動執行：

```powershell
# 終端機 1 — 後端
start_backend.bat
#   等同：venv\Scripts\uvicorn.exe backend.main:app --reload

# 終端機 2 — 前端
start_frontend.bat
#   等同：cd frontend && npm run dev
```

啟動後開瀏覽器：

| 服務 | 網址 |
|------|------|
| 前端畫面 | <http://localhost:5173> |
| 後端 API 文件（Swagger） | <http://127.0.0.1:8000/docs> |

> 後端終端機視窗會即時印出買賣訊號與監聽 log，跑 Bot 時留著看。

## 3. 前端操作流程（4 分頁）

| 分頁 | 用途 |
|------|------|
| **儀表板** | 帳戶總損益、AI 市場燈號、服役中 Bot 卡片（啟動/停止/手動執行/刪除） |
| **AI 探勘** | AI 盤前漏斗海選（量能 → 情緒 → EV）→ 高期望值推薦卡 → 按「一鍵 Deploy」自動建 Bot 並掛排程 |
| **K 線圖** | 原生蠟燭圖 + 即時報價 + 風控水位線；可切「網格」同時看 4 檔。**拖曳止損/止盈線即可即時改後端風控**（進場均價線是真實成交價、不可拖） |
| **基本面** | 查代號 → 公司資料、財報三表、配息分割、相關新聞 |
| 右側 **策略工作台** | 策略方案 CRUD、一鍵回測、EV 歷史榜、LLM 思考助手（可收合/拉寬） |

### 典型一輪操作

1. **AI 探勘** 分頁 → 看 AI 推薦清單（EV > 0 的策略配置）
2. 挑一張順眼的 → 按 **一鍵 Deploy** → 系統自動建 Bot 並開始監聽（全程 Paper）
3. **儀表板** 確認 Bot 顯示「啟用中」、看最後檢查時間在跳
4. **K 線圖** 盯走勢與水位線；想調風控就直接拖止損/止盈線
5. 系統依止盈 / 止損 / 追蹤止損自動出場 → 交易紀錄寫進資料庫、發 LINE/Discord 通知

> 也可手動：右側 **策略工作台** 自訂方案 → 一鍵回測看 EV → 滿意再建 Bot。

## 4. 檔案 / 紀錄位置

| 紀錄 | 位置 | 怎麼看 |
|------|------|--------|
| **資料庫（全部）** | 根目錄 `albee_stock.db`（SQLite） | 含下列 4 張表 |
| └ Bot 設定 | `bots` 表 | 儀表板 / `GET /bots` |
| └ **交易紀錄** | `trade_logs` 表 | 「交易紀錄」表 / `GET /orders` |
| └ **回測歷史**（含 EV 指標） | `backtest_runs` 表 | 策略工作台 EV 榜 / `GET /backtest-runs` |
| └ 策略方案 | `strategy_presets` 表 | 策略工作台 / `GET /presets` |
| **探討 / 檢討筆記** | `explorations/`（`INDEX.md` 路標 + 每筆一檔，**進 git**） | LLM 助手寫入 |
| **API 金鑰** | `.env`（根目錄，**不進 git**） | 文字編輯器 |
| **買賣訊號 log** | 後端終端機視窗（stdout） | 跑 Bot 時看終端機 |
| **即時通知** | LINE / Discord 推播 | 手機（非檔案） |

## 5. 安全防線（真錢雙閘）

實盤下單有**雙閘安全閥**，要同時滿足兩個條件才會送真錢單：

1. `ALPACA_BASE_URL` 改成實盤網址 `https://api.alpaca.markets`
2. `ALLOW_LIVE_TRADING=true`

預設兩道都關 = 純模擬，手滑也燒不到錢。**務必先在 Paper 模式把策略、止盈止損驗證到滿意，再考慮實盤，風險自負。**

另有 **LLM 外送閘** `LLM_ALLOW_CLOUD`（預設 `false`）：助手會把策略/回測資料注入 prompt，
若 LLM 指向外部雲端會把資料送出本機。預設只允許本機 Ollama；要用雲端供應商須明確設 `true`。

## 6. 常見問題

**Q：畫面沒有「AI 探勘」分頁 / 還是亮色舊版？**
A：程式碼版本太舊。`git pull` 拉最新（`main` 或 `develop` 分支）後重啟前端。

**Q：AI 探勘 / 助手按了沒反應或報錯？**
A：本機 LLM 沒開。先 `ollama serve` 並確認已 `ollama pull llama3.1`；不想用 AI 就略過該功能。

**Q：帳戶餘額 / 報價抓不到？**
A：檢查 `.env` 金鑰是否正確（Paper 金鑰開頭 `PK`），或先跑 `venv\Scripts\python.exe backend\test_connection.py` 測連線。

**Q：資料庫壞了 / 想重來？**
A：停掉後端 → 刪 `albee_stock.db` → `setup.bat` 重建空庫（Bot 與交易紀錄會清空）。
