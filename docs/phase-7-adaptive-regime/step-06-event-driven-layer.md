# 步驟 6 — 事件驅動層（情緒當過濾，不當主力）

> 區塊 1。你最想要、但**最該保持克制**的一塊。回到 [Phase 7 索引](README.md)。

## 目標

把「聯準會 / 總統發言 / 重大新聞」納入決策——但定位是**否決閘 / 風險過濾器**，
**不是進場主力**。理由見 [Phase 7 索引第貳節](README.md#貳可行性誠實評估把能做的與夢碎的分開)。

## 概念名稱

**事件驅動交易（Event-Driven Trading）** + **經濟事件日曆（Economic Calendar）** + **NLP 情緒分析**。
聯準會這套又叫 **Fed-watching**。

## 殘酷的現實（先讀，免得做白工）

| 你的願景 | 現實限制 |
|----------|----------|
| 「精準抓住演講時間」 | 需**事件日曆 feed**；我們現在只有日線，**抓不到盤中分秒** |
| 「讀內容推測漲跌」 | 市場**毫秒級**消化排程事件，retail 用日線 + 本機 Llama 永遠慢一步；LLM 也**無可靠方向預測力** |
| 「給出漲跌意見」 | 能做「鷹派 / 鴿派」摘要，但**別把它當買賣訊號**——常常利空出盡反漲 |

> **所以這層的正確用法：不是「LLM 說會漲就買」，而是「重大事件前後 / LLM 偵測到強烈利空 → 暫停開新倉 / 縮小部位」。** 把它當煞車，不當油門。

## 改動構想（務實、漸進）

1. **第一版（現在做得到）**：升級現有情緒層當**否決閘**——重大負面情緒 → 否決該標的部署（已在 Phase 6 [步驟 7](../phase-6/step-07-sentiment-into-decision.md) 接進決策，這裡延伸成「事件期間風險閘」）。
2. **第二版（需升級資料）**：接**經濟事件日曆**（如 FOMC 日期），事件前後 N 小時自動降風險 / 不開新倉。
3. **第三版（需付費 / 日內資料，列為遠期）**：日內新聞 + 即時報價，才談得上「抓演講時點反應」。**前期不做。**

## 重用現有

- `fundamentals.get_news` + `llm.complete` + `screener.parse_sentiment`（情緒管線已存在）。
- Phase 6 [步驟 7](../phase-6/step-07-sentiment-into-decision.md) 的 `apply_sentiment`（否決邏輯已建立，這裡擴充事件時間維度）。
- LLM 外送安全閥 `LLM_ALLOW_CLOUD`（事件解讀仍受隱私閘約束）。

## 過擬合 / 風險

- 「事件→漲跌」的回測**極易洩漏未來**（必須用 point-in-time 新聞），數字漂亮多半是假的。
- LLM 情緒會飄、會幻覺；當**輔助過濾**容錯高，當**主訊號**會害死你。
- 不要為了「看起來很 AI」而把這層做大——它的 ROI 在三塊裡最低。

## 驗收

- 重大負面事件 / 情緒期間，系統**降風險（不開新倉 / 縮部位）**，而非據此猜方向重壓。
- 情緒層全程是 best-effort：LLM 連不上 / 沒事件資料時，系統照常運作（不阻斷）。
- **明確不宣稱「能預測聯準會後漲跌」**——文件與 UI 都誠實標示為「風險過濾」。
