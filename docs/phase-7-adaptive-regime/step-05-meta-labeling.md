# 步驟 5 — meta-labeling 二級模型

> 區塊 3 進階。這是你願景裡「該不該下、下多重」最精準的學術對應。回到 [Phase 7 索引](README.md)。

## 目標

在「策略給了進場訊號」之後，再加一個**二級判斷**：這個訊號**值不值得實際下注？該下多重？**
過濾掉品質差的訊號，把資金集中在高勝率的訊號上。

## 概念名稱

**元標籤（Meta-Labeling）** — 出自 López de Prado《Advances in Financial Machine Learning》。
你說的「用 C 策略、勝率多少、投多少量」幾乎就是 meta-labeling 的定義：
- **一級模型（primary）**：決定**方向**（買 / 賣）← 我們的策略 + 步驟 3 的選擇器。
- **二級模型（secondary / meta）**：決定**要不要執行 + 下注大小**（預測「這個一級訊號會成功的機率」）。

## 為什麼這個設計很聰明

- 一級模型只管「方向對不對」（追求高召回，盡量不漏機會）。
- 二級模型只管「這次該不該信」（追求高精確，過濾爛訊號）。
- 分工後，二級模型的輸出「成功機率 p」可**直接餵給凱利**（步驟 4）當 W，部位大小就有了。

## 改動構想

- **先用簡單規則當 meta（建議起步）**：把步驟 1 的特徵 + 步驟 2 的狀態當條件，寫「在這些情境下才放行一級訊號」的規則。零過擬合、可解釋。
- **再選配學習式 meta**：用歷史「一級訊號 + 後續是否獲利」當標籤，訓練二級分類器輸出 `p(成功)`。**必經步驟 7 的 purged CV**。
- 新增 `backend/services/meta_label.py`：`should_take(signal, features, regime) -> (bool, confidence)`。
- 接線：`confidence` → 步驟 4 凱利的 W → 部位大小。

## 重用現有

- 步驟 1 特徵、步驟 2 狀態、步驟 4 凱利（meta 的輸出正好接凱利的輸入）。
- 既有 `BacktestRun` / 交易紀錄（學習式 meta 的標籤來源）。

## 過擬合 / 風險

- 學習式 meta-labeling **是 ML，過擬合風險高**，且標籤建構（三柵欄法 triple-barrier 等）有不少眉角。
- **務必先做規則式 meta**，證明「加了過濾真的提升 OOS EV」再考慮學習式。
- 二級模型的 `p` 若高估，會經由凱利放大成過大部位——**OOS 校準（calibration）很重要**。

## 驗收

- 規則式 `should_take`：對低品質情境的一級訊號正確否決，對高品質情境放行。
- 加 meta 過濾後，OOS 的 profit factor / EV 提升（**沒提升就砍掉這層**）。
- meta 的 confidence 接進凱利後，高信心訊號部位較大、低信心較小或不下注。
