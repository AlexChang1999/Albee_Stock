# 步驟 1 — 市場狀態特徵工程

> 區塊 2 的地基。回到 [Phase 7 索引](README.md)。

## 目標

把「現在市場長什麼樣」量化成一組**數字特徵**，作為後續「狀態分類器」與「自適應選策略」的輸入。
你說的「A 股量大卻沒漲幅」就是其中一個特徵組合（量比高 + 報酬率近 0 = 量價背離）。

## 概念名稱

**特徵工程（Feature Engineering）** / 市場狀態描述子（Regime Descriptors）。純 pandas 算得出來，不需 ML。

## 候選特徵（每根 K 棒算一組，全部純 pandas）

| 特徵 | 直覺 | 對應你的願景 |
|------|------|-------------|
| `volume_ratio` | 最新量 ÷ 近 20 日均量 | 「交易量變很大」← **screener 已經有了** |
| `return_5d` / `return_20d` | 近 5/20 日報酬率 | 「卻沒什麼漲幅」（量大但 return≈0 = 量價背離） |
| `volatility_20d` | 近 20 日報酬標準差（年化） | 高波動 / 低波動狀態 |
| `trend_strength` | 收盤對 20/60 日均線的位置 + 斜率，或 ADX | 趨勢盤 vs 盤整盤 |
| `atr_pct` | ATR ÷ 價格 | 波動幅度（給止損 / 部位用） |
| `range_position` | 收盤在近 N 日高低區間的位置（唐奇安%） | 突破 vs 回檔 |

## 改動構想

- 新增純函式模組 `backend/services/regime_features.py`：`compute_features(df) -> dict`（吃 K 線 DataFrame，回一組當下特徵）。
- 全部純 pandas、無未來函數（只用 `df.iloc[:i+1]`，與回測同款 walk-forward 紀律）。
- 特徵定義集中一處，回測層與實盤層共用（呼應 Phase 6「回測=實盤」鐵則）。

## 重用現有

- `screener.volume_ratio`（直接搬進來當第一個特徵，避免重複定義）。
- 既有策略裡算指標的 pandas 慣例（均線 / ATR / 唐奇安通道已有現成寫法可參考）。

## 過擬合風險

- **特徵不是越多越好**：每多一個特徵，後續分類器就多一個過擬合自由度。先用 4~6 個有直覺的，別一次塞 30 個。
- 特徵必須是**可解釋**的（你看得懂「為什麼這個數字代表爆量滯漲」），黑箱特徵日後無法除錯。

## 驗收

- `compute_features(df)` 對任一標的回出一組數值；「量大滯漲」的歷史日子，`volume_ratio` 高且 `return_5d`≈0。
- 無未來函數：對 `df.iloc[:i+1]` 與完整 `df` 在第 i 根算出的特徵一致。
- 純函式單元測試（合成序列驗每個特徵算對）。
